Finger PPG Lab ♥

Estimate heart rate from fingertip color intensity changes using the rear camera and phone flashlight. All processing takes place in your browser; video is never uploaded.

Participant information

Five-second BPM summaries are saved on this device when you stop (automatic stop after 120 seconds). Use a participant ID instead of a real name for classroom research. Export before clearing browser data.
